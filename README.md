# Northwind Sales Analytics Portfolio

## Project Overview
This project leverages the classic **Northwind dataset** to build an end-to-end Business Intelligence solution in **Power BI**. By transforming raw transactional data into interactive visual stories, this dashboard provides a 360-degree view of sales performance, customer loyalty, and inventory health. It empowers stakeholders to move beyond intuition and make high-stakes decisions based on real-time KPIs and trend analysis.

## Core Analysis Pillars
* **Sales Performance:** Monitoring revenue growth, profit margins, and Year-over-Year (YoY) trends to track business health.
* **Customer Behavior:** Identifying high-value segments and purchasing patterns to drive retention and targeted marketing.
* **Product Trends:** Highlighting top-selling categories and identifying stock risks to optimize supply chain management.
* **Employee Insights:** Tracking sales representative performance to identify top talent and optimize regional operations.

## Technical Stack
* **Database:** MySQL / Northwind Dataset (SQL for schema refinement).
* **ETL & Cleaning:** Power Query (M Language) for data transformation.
* **Data Modeling:** Star Schema design with advanced DAX for dynamic measures.
* **Visualization:** Power BI Desktop featuring interactive filters and drill-through reporting.
